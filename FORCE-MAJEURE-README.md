# Форс-мажоры — интеграция в Startup Tycoon

Добавлены `force-majeure.js`, `force-majeure.json`, модальное окно в `index.html` и стили в `style.css`. В `script.js` добавлены два вызова: проверка на игровом тике и проверка после найма первого сотрудника.

## Как работает
- События не могут появиться, пока `employees.length === 0`.
- Периодическая проверка выполняется на игровых тиках, не чаще одного раза в 8 тиков; вероятность выбора события определяется `weight`.
- После найма первого сотрудника выполняется отдельная проверка/попытка события.
- Очередь гарантирует одно активное модальное окно.
- Последствия ограничивают деньги снизу нулём, репутацию/продукт/настроение/энергию — диапазоном 0–100.
- Пока окно открыто, игровой таймер приостанавливается; затем возвращается прежнее состояние паузы.

## Добавление события без правки JS
Добавьте объект в `force-majeure.json`:
```json
{
  "id": "office_power",
  "type": "office",
  "title": "Отключили электричество",
  "description": "В офисе пропало питание.",
  "weight": 3,
  "conditions": { "minEmployees": 1, "minDay": 2, "minMoney": 100 },
  "choices": [
    { "id": "generator", "label": "Арендовать генератор", "effects": { "money": -200, "rep": 2 } },
    { "id": "wait", "label": "Подождать", "effects": { "rep": -3, "employeeMood": -5 } }
  ]
}
```
Поддерживаемые условия: `minEmployees`, `minDay`, `minMoney`, `minRep`. Типы отображения задаются в объекте `TYPE` в `force-majeure.js`. Для нового типа добавьте там иконку, подпись и цвет; сами условия и последствия менять не нужно.

## Последствия
Поддерживаются `money`, `rep`, `product`, `employeeMood`, `employeeEnergy`. Чтобы воздействовать на другие параметры игры, расширьте функцию `resolve()` в `force-majeure.js` или обработчик `onApplied` в `script.js`.

## Проверка
`node --check script.js` и `node --check force-majeure.js` проходят. После распаковки установите зависимости командой `npm install`, задайте `.env` при необходимости и запустите `npm start`.
