# 🚀 Startup Tycoon

**Построй стартап с нуля — от первой задачи до процветающей компании.**

Startup Tycoon — браузерная игра-тайкун, где ты нанимаешь команду, распределяешь задачи и развиваешь свой продукт. Следи за деньгами и состоянием сотрудников, принимай управленческие решения и превращай небольшую компанию в успешный бизнес.

## ✨ Возможности

- 👤 Регистрация и вход по имени пользователя и паролю.
- 🧑‍💻 Найм сотрудников с разными ролями и характеристиками.
- 📋 Назначение задач и управление рабочим процессом.
- ⚡ Учёт энергии, настроения и эффективности команды.
- 🏢 Офис с простой спрайтовой графикой.
- 💾 Сохранение игрового прогресса для аккаунта.
- 📱 Интерфейс, рассчитанный на браузер и адаптацию под разные экраны.

> Состав возможностей зависит от текущей версии проекта.

## 🎮 Игровой процесс

Ты управляешь небольшой компанией: нанимаешь сотрудников, подбираешь им задачи и следишь за развитием стартапа. Навыки и состояние команды влияют на скорость работы. Планируй расходы, улучшай продукт и привлекай новых клиентов.

## 🚀 Запуск проекта

### Требования

- Git
- Node.js и npm, если проект использует Node.js

### Установка

```bash
git clone https://github.com/M1ST0R/startup_tycoon.git
cd startup_tycoon
npm install
```

Создай локальный файл `.env`, если он требуется серверу. Используй `.env.example` как образец и укажи собственные настройки для разработки.

Запусти проект командой, предусмотренной в `package.json`. Например:

```bash
npm run dev
```

или:

```bash
npm start
```

После запуска открой адрес, который сервер выведет в терминале.

## 🔐 Безопасность

- Не добавляй файл `.env` и секреты в Git.
- Не отправляй в репозиторий пароли, токены и другие учётные данные.
- Проверь `.gitignore`: в нём должны быть исключены как минимум `.env`, `node_modules/` и локальные файлы базы данных.

## 📁 Структура проекта

Структура зависит от текущей реализации. Основные части проекта:

- **Клиент** — игровой интерфейс, сцена офиса и взаимодействие с игроком.
- **Сервер** — регистрация, вход и обработка игровых данных.
- **База данных** — аккаунты и сохранения игроков.
