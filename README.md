# 🚀 Startup Tycoon

**Построй стартап с нуля — от первой задачи до процветающей компании.**

Startup Tycoon — браузерная игра-тайкун, где ты нанимаешь команду, распределяешь задачи и развиваешь свой продукт. Следи за деньгами и состоянием сотрудников, принимай управленческие решения и превращай небольшую компанию в успешный бизнес.

## ✨ Возможности

- 👤 Регистрация и вход по имени пользователя и паролю
- 🧑‍💻 Найм сотрудников с разными ролями и характеристиками
- 📋 Назначение задач и управление рабочим процессом
- ⚡ Учёт энергии, настроения и эффективности команды
- 🎚️ Три уровня сложности: скорость сотрудников, трудоёмкость проектов и разные цели кампании
- 🏢 Офис с простой спрайтовой графикой
- 💾 Сохранение игрового прогресса для аккаунта
- 📱 Адаптивный интерфейс под разные экраны

## 🎮 Игровой процесс

Ты управляешь небольшой компанией: нанимаешь сотрудников, подбираешь им задачи и следишь за развитием стартапа. Навыки и состояние команды влияют на скорость работы. Планируй расходы, улучшай продукт и привлекай новых клиентов. Перед новой кампанией выбери режим: «Лёгкий» помогает освоиться, «Средний» задаёт базовый баланс, а «Хардкор» замедляет команду, повышает трудоёмкость проектов и увеличивает требования к успеху.

## 🚀 Запуск проекта

### Требования

- Git
- Node.js 24.22.1 LTS

### Установка

```bash
git clone https://github.com/M1ST0R/startup_tycoon.git
cd startup_tycoon
npm install
```

Запусти проект:

```bash
npm run dev
```

После запуска открой адрес, который сервер выведет в терминале.

## 📁 Структура проекта

- **Клиент** — игровой интерфейс, сцена офиса и взаимодействие с игроком
- **Сервер** — регистрация, вход и обработка игровых данных
- **База данных** — аккаунты и сохранения игроков
